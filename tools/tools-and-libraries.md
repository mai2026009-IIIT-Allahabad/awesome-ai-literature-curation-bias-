# 🛠️ Tools & Libraries

Tools and libraries that can help researchers collect, explore,
analyze, and evaluate scientific literature and citation patterns.

---

## 1. OpenAlex

**Type:** Scholarly Data API

OpenAlex provides open scholarly metadata for works, authors,
institutions, topics, publishers, and citation relationships.

### Useful for

- Finding research papers
- Collecting citation counts
- Exploring authors and institutions
- Studying research topics
- Building citation datasets
- Analyzing highly cited papers

🔗 [OpenAlex Documentation](https://openalex.mintlify.app/)

---

## 2. Semantic Scholar API

**Type:** Scholarly Search & Citation API

Semantic Scholar provides programmatic access to papers, authors,
citations, references, and paper recommendations.

### Useful for

- Searching scientific papers
- Retrieving paper metadata
- Exploring citations and references
- Studying paper recommendations
- Building literature-search systems

🔗 [Semantic Scholar API](https://www.semanticscholar.org/product/api)

---

## 3. OpenCitations

**Type:** Open Citation Database & API

OpenCitations provides open citation data that can be used to explore
relationships between scholarly publications.

### Useful for

- Citation counts
- Citation networks
- Finding citing papers
- Finding cited papers
- Building citation graphs
- Citation analysis

🔗 [OpenCitations API](https://opencitations.net/)

---

## 4. Bibliometrix / Biblioshiny

**Type:** Bibliometric Analysis Tool

Bibliometrix is an R package for quantitative bibliometric and
scientometric analysis. Biblioshiny provides a graphical interface
for users who do not want to write R code.

### Useful for

- Citation analysis
- Co-citation analysis
- Bibliographic coupling
- Co-authorship networks
- Keyword analysis
- Research trend analysis
- Science mapping

🔗 [Bibliometrix](https://www.bibliometrix.org/)

---

## 5. CiteLab

**Type:** LLM Citation Research Toolkit

CiteLab is a toolkit for developing, evaluating, and diagnosing
LLM-based citation-generation workflows.

### Useful for

- LLM citation generation
- Citation workflow evaluation
- Diagnosing citation behavior
- Human-LLM interaction
- Reproducible citation experiments

🔗 [CiteLab Paper](https://aclanthology.org/2025.acl-demo.47/)

🔗 [CiteLab GitHub](https://github.com/SjJ1017/Citelab)

---

## 🧭 Suggested Workflow

A newcomer can combine these tools as follows:

OpenAlex / Semantic Scholar
        ↓
Find and collect papers
        ↓
OpenCitations
        ↓
Build citation relationships
        ↓
Bibliometrix
        ↓
Analyze citation patterns
        ↓
CiteLab
        ↓
Study LLM citation behavior
