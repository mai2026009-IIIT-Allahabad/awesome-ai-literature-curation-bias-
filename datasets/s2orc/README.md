# S2ORC

## Source
Allen Institute for AI / Semantic Scholar

## Description
S2ORC (Semantic Scholar Open Research Corpus) is a scientific-paper
corpus designed for NLP and text-mining research. It provides
bibliographic information, references, and structured scientific
paper content.

## Application

S2ORC can be used for:

- Citation-context analysis
- Reference analysis
- Scientific text mining
- Literature retrieval experiments
- NLP-based literature analysis

## Access

https://github.com/allenai/s2orc

## Important Limitation

S2ORC should not be treated as the only dataset for measuring
English-language bias. A multilingual comparison requires additional
non-English or multilingual literature sources.

## Repository Usage

Do not upload the complete S2ORC dataset. Provide access instructions
and analysis scripts instead.
