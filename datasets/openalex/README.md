# OpenAlex

## Source
OpenAlex

## Description
OpenAlex is an open scholarly catalog containing information about
research works, authors, sources, institutions, topics, publishers,
and their relationships.

## Application

OpenAlex can be used in this repository to investigate citation bias by
comparing highly cited and less-cited research.

Possible analyses include:

- Citation count distribution
- Highly cited vs. low-citation papers
- Publication year
- Research venues
- Authors and institutions
- Topic distribution
- Citation relationships

## Access

https://openalex.org/

## Documentation

https://developers.openalex.org/

## Repository Usage

The complete OpenAlex dataset should not be uploaded to this repository.
Researchers can access the data through the OpenAlex API or download
appropriate subsets for analysis.
