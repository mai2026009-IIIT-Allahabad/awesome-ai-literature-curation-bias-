# Datasets

This directory contains information about datasets that can support research on
recall bias toward highly cited and English-language papers in AI literature
curation.

The datasets are not redistributed in this repository because of their size,
licensing, or access requirements. Instead, this directory provides information
about their source, purpose, application, and official access links.

| Dataset | Source | Description | Application | Link |
|---|---|---|---|---|
| OpenAlex | OpenAlex | Open scholarly catalog containing works, authors, sources, institutions, topics, and citation connections. | Analyze citation counts, publication patterns, and highly cited vs. less-cited papers. | https://openalex.org/ |
| Semantic Scholar Academic Graph | Semantic Scholar | Scholarly dataset containing papers, authors, abstracts, citations, and related metadata. | Study citation networks and literature recommendation patterns. | https://www.semanticscholar.org/ |
| S2ORC | Allen Institute for AI / Semantic Scholar | Scientific-paper corpus containing metadata, references, and structured full text. | Analyze papers, references, citation contexts, and literature retrieval. | https://github.com/allenai/s2orc |
| OpenCitations | OpenCitations | Open scholarly citation data and citation relationships. | Study citation networks and the Matthew Effect. | https://opencitations.net/ |
| SciFact | Allen Institute for AI | Dataset containing scientific claims and evidence-containing abstracts with verification labels. | Study whether cited/retrieved papers actually support scientific claims. | https://github.com/allenai/scifact |
