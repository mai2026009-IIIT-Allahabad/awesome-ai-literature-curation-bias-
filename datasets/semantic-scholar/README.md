# Semantic Scholar Academic Graph

## Source
Semantic Scholar

## Description
The Semantic Scholar Academic Graph provides scholarly information
including papers, authors, abstracts, citations, and related metadata.

## Application

This dataset can be used to:

- Analyze citation networks
- Compare highly cited and less-cited papers
- Study paper visibility
- Investigate literature recommendation patterns
- Analyze relationships between papers and authors

## Access

https://www.semanticscholar.org/product/api

## Dataset Access

Semantic Scholar provides downloadable Academic Graph datasets.

## Repository Usage

Only scripts, documentation, or small samples should be stored in this
repository. The complete dataset should not be uploaded.
