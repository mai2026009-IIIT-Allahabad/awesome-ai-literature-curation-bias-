# 🔧 GitHub Implementations

Open-source implementations related to AI-assisted literature search,
citation recommendation, scholarly ranking, and bias evaluation.

The repositories below are selected based on **quality and research
relevance**, rather than GitHub stars alone.

## 📋 Selection Criteria

Each repository is considered using the following criteria:

- 📖 Documentation quality
- 💻 Availability and clarity of source code
- 🔄 Recent maintenance and activity
- 🧪 Examples, notebooks, or tutorials
- ♻️ Reproducibility
- 📜 Clear open-source license
- 📚 Connection to a research paper or recognized project

---

## 🔎 Literature Retrieval & Recommendation

### 1. LLMScholarBench

**Focus:** LLM-based scholar recommendation auditing

LLMScholarBench provides a framework for auditing scholar
recommendations generated by Large Language Models. It includes
components for generating recommendations, building ground truth,
and evaluating recommendation behavior.

**Why it is relevant:**  
Directly related to investigating whether LLM-based scholarly
recommendation systems exhibit systematic biases.

- 🔗 **GitHub:** https://github.com/CSHVienna/LLMScholarBench
- 📄 **Research:** Connected to research on auditing LLM scholar
  recommendations.

---

### 2. LitSearch

**Focus:** Scientific literature retrieval

LitSearch provides a benchmark and implementation for evaluating
scientific literature search and retrieval systems.

**Why it is relevant:**  
Literature curation begins with retrieval. Bias at the retrieval stage
can affect which papers are ultimately considered or recommended.

- 🔗 **GitHub:** https://github.com/princeton-nlp/LitSearch
- 📄 **Paper:** https://aclanthology.org/2024.emnlp-main.1053/

---

### 3. CiteGen

**Focus:** Context-aware citation recommendation

CiteGen is an LLM-based system designed to recommend citations based
on the context of a scientific document.

**Why it is relevant:**  
Citation recommendation systems can influence which papers receive
visibility and which papers are selected as supporting references.

- 🔗 **GitHub:** https://github.com/Marcomurgia97/CiteGen-An-LLM-Based-System-for-Context-Aware-Citation-Recommendation

---

### 4. ScholarLoop

**Focus:** Evidence-grounded academic search

ScholarLoop explores an evidence-grounded approach to academic search
and recommendation.

**Why it is relevant:**  
It demonstrates how an AI literature-curation system can combine
retrieval, ranking, evidence, and citation verification.

- 🔗 **GitHub:** https://github.com/124-creator/ScholarLoop

---

## 🌐 Language & Scholarly Bias

### 5. LOBSTER

**Focus:** Language-of-study bias in scientific peer review

LOBSTER provides a dataset and implementation for studying
language-related bias in scientific peer review.

**Why it is relevant:**  
Language bias is an important part of understanding why research
written about or in different languages may receive different
treatment in scientific workflows.

- 🔗 **GitHub:** https://github.com/GGLAB-KU/LOBSTER
- 📄 **Research:** Related to research on language-of-study bias in
  scientific peer review.

---

### 6. LLM Review Bias

**Focus:** Bias in LLM-assisted peer review

This project provides code and experimental resources for studying
potential biases in LLM-assisted academic peer review.

**Why it is relevant:**  
Although focused on peer review rather than literature retrieval,
the project demonstrates how researcher and paper characteristics
can influence AI-assisted scholarly evaluation.

- 🔗 **GitHub:** https://github.com/ivaxi0s/llm-review-bias

---

## 🧠 Ranking & Evaluation

### 7. LLMRanker

**Focus:** LLM-based ranking

LLMRanker provides implementations for using Large Language Models
for ranking and investigates issues such as position bias.

**Why it is relevant:**  
Ranking is a critical stage in literature curation. Even when relevant
papers are retrieved, ranking bias can determine which papers appear
at the top of the results.

- 🔗 **GitHub:** https://github.com/shangeth/llmranker
