# 🔧 GitHub Implementations

Open-source projects that can help researchers collect scholarly
literature, analyze citation patterns, and audit AI-based
recommendation systems.

---

## 1. LLMScholarBench ⭐

**Focus:** LLM-based scholar recommendation auditing

LLMScholarBench provides an implementation for auditing
LLM-based scholar recommendations. It includes components for
calling LLMs, auditing recommendations, building ground truth,
and collecting scholarly data from OpenAlex.

🔗 [GitHub Repository](https://github.com/CSHVienna/LLMScholarBench)

**Best for:** Researchers studying bias in LLM-based recommendations.

---

## 2. OpenAlex API Tutorials

**Focus:** Scholarly data & bibliometric analysis

A collection of Jupyter notebooks demonstrating how to use
OpenAlex for bibliometric analysis.

🔗 [GitHub Repository](https://github.com/ourresearch/openalex-api-tutorials)

**Best for:** Beginners learning how to collect and analyze
scholarly metadata.

---

## 3. OpenAlex Bibliometric Reports

**Focus:** Citation and bibliometric analysis

A reproducible Python workflow for collecting OpenAlex data
and generating bibliometric reports.

🔗 [GitHub Repository](https://github.com/UA-Libraries-Research-Data-Services/openalex-bibliometric-reports)

**Best for:** Citation patterns, research trends, and
bibliometric analysis.

---

## 4. PyAlex

**Focus:** OpenAlex Python library

A Python interface for searching, filtering, and analyzing
OpenAlex scholarly data.

🔗 [GitHub Repository](https://github.com/J535D165/pyalex)

**Best for:** Building your own literature and citation
analysis scripts.

---

## 5. CiteLens

**Focus:** Citation networks & paper recommendation

A research tool for exploring citing papers, citation impact,
relevance, and academic paper recommendations.

🔗 [GitHub Repository](https://github.com/kishormorol/CiteLens)

**Best for:** Exploring citation networks and literature
recommendation.
